# Iyu.VaultAI

Scheduled report generation and the chat-widget embed proxy for a vault-ai service, hosted in an Iyu application.

```
dotnet add package Iyu.VaultAI
```

**Documentation:** [Scheduled reports (`Iyu.VaultAI`)](https://github.com/iyulab/iyu-framework-v5#scheduled-reports-iyuvaultai) in the repository README.

`Iyu.VaultAI` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
