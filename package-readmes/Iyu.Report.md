# Iyu.Report

Fills Office document templates with data through DocuChef; unrelated to Iyu.VaultAi's scheduled reports.

```
dotnet add package Iyu.Report
```

**Documentation:** [Document templates (`Iyu.Report`)](https://github.com/iyulab/iyu-framework-v5#document-templates-iyureport) in the repository README.

`Iyu.Report` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
