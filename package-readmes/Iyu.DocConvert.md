# Iyu.DocConvert

Converts documents to PDF through a self-hosted Gotenberg instance.

```
dotnet add package Iyu.DocConvert
```

**Documentation:** [Document conversion (`Iyu.DocConvert`)](https://github.com/iyulab/iyu-framework-v5#document-conversion-iyudocconvert) in the repository README.

`Iyu.DocConvert` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
