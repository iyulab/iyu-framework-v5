# Iyu.Lowline

Runs the Lowline engine, which learns suggestions for form fields from confirmed records, in any .NET host over two storage ports the host provides; it depends on neither Entity Framework Core nor Iyu.Core.

```
dotnet add package Iyu.Lowline
```

**Documentation:** [Learning from confirmed records (`Iyu.Lowline`)](https://github.com/iyulab/iyu-framework-v5#learning-from-confirmed-records-iyulowline) in the repository README.

`Iyu.Lowline` is versioned on its own line, separate from the other `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5); its [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/src/Iyu.Lowline/CHANGELOG.md) is shipped in this package. MIT licensed.
