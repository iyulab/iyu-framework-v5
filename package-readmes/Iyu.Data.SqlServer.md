# Iyu.Data.SqlServer

Names SQL Server's error numbers by their SQLSTATE so a failed write is classified; reference it only on SQL Server.

```
dotnet add package Iyu.Data.SqlServer
```

**Documentation:** [Layers](https://github.com/iyulab/iyu-framework-v5#layers) in the repository README.

`Iyu.Data.SqlServer` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
