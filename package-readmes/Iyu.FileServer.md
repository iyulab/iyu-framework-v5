# Iyu.FileServer

A token-gated file byte gateway for ASP.NET Core, with Azure Blob and local filesystem backends.

```
dotnet add package Iyu.FileServer
```

**Documentation:** [File gateway (`Iyu.FileServer`)](https://github.com/iyulab/iyu-framework-v5#file-gateway-iyufileserver) in the repository README.

`Iyu.FileServer` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
