# Iyu.Notifications.EntityFrameworkCore

Entity Framework Core stores behind Iyu.Notifications - the inbox, the record of unreached events and the administrators' target table - over the application's own DbContext tables.

```
dotnet add package Iyu.Notifications.EntityFrameworkCore
```

**Documentation:** [Telling people what happened (`Iyu.Notifications`)](https://github.com/iyulab/iyu-framework-v5#telling-people-what-happened-iyunotifications) in the repository README.

`Iyu.Notifications.EntityFrameworkCore` shares the version of the other `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5) and builds on `Iyu.Notifications`, which has its own line; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
