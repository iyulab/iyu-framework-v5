# Iyu.Server.Chat

Adapter that serves BareChat chat endpoints from an Iyu host.

```
dotnet add package Iyu.Server.Chat
```

**Documentation:** [Chat (`Iyu.Server.Chat`)](https://github.com/iyulab/iyu-framework-v5#chat-iyuserverchat) in the repository README.

`Iyu.Server.Chat` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
