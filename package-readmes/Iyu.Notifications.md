# Iyu.Notifications

Host-neutral notification routing - events declared in code, recipients resolved from users and roles, an inbox with read and handled state, and a record of events nobody could be reached for; it depends on neither Entity Framework Core nor Iyu.Core.

```
dotnet add package Iyu.Notifications
```

**Documentation:** [Telling people what happened (`Iyu.Notifications`)](https://github.com/iyulab/iyu-framework-v5#telling-people-what-happened-iyunotifications) in the repository README.

`Iyu.Notifications` is versioned on its own line, separate from the other `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5); its [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/src/Iyu.Notifications/CHANGELOG.md) is shipped in this package.
