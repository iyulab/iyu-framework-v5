# Iyu.MainServer.GraphQL

The GraphQL surface for Iyu.MainServer; reference it only if the host serves GraphQL.

```
dotnet add package Iyu.MainServer.GraphQL
```

**Documentation:** [Layers](https://github.com/iyulab/iyu-framework-v5#layers) in the repository README.

`Iyu.MainServer.GraphQL` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
