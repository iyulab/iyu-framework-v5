# Iyu.MainServer.OpenIdConnect

OpenID Connect back-channel logout for Iyu.MainServer hosts that sign people in through an OpenID Connect provider.

```
dotnet add package Iyu.MainServer.OpenIdConnect
```

**Documentation:** [Identity](https://github.com/iyulab/iyu-framework-v5#identity) in the repository README.

`Iyu.MainServer.OpenIdConnect` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
