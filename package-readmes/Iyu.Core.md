# Iyu.Core

Entity base class, marker attributes, value objects and the identity and attachment contracts the other Iyu packages build on; it depends on nothing else in the stack.

```
dotnet add package Iyu.Core
```

**Documentation:** [Layers](https://github.com/iyulab/iyu-framework-v5#layers) in the repository README.

`Iyu.Core` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
