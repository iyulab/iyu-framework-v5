# Iyu.UBoard.IronHive

Fills the Iyu.UBoard assistant port with IronHive.Agent and IronProw: a board's chat answered by any OpenAI-compatible model service the host names, with the host's own key, model and limits.

```
dotnet add package Iyu.UBoard.IronHive
```

**Documentation:** [Keeping boards and their history (`Iyu.UBoard`)](https://github.com/iyulab/iyu-framework-v5#keeping-boards-and-their-history-iyuuboard) in the repository README.

`Iyu.UBoard.IronHive` shares the version of the other `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5) and builds on `Iyu.UBoard`, which has its own line; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
