# Iyu.Data

Entity Framework Core base DbContext for Iyu entities, with timestamp and UTC-normalizing interceptors and value converters for the Iyu value objects.

```
dotnet add package Iyu.Data
```

**Documentation:** [Layers](https://github.com/iyulab/iyu-framework-v5#layers) in the repository README.

`Iyu.Data` is one of the `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5), which share one version; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
