# Iyu.UBoard.MainServer

Connects the Iyu.UBoard source catalog to Iyu.MainServer: what a board can be built from is the host's OData model, listed as the caller's read policies allow.

```
dotnet add package Iyu.UBoard.MainServer
```

**Documentation:** [Keeping boards and their history (`Iyu.UBoard`)](https://github.com/iyulab/iyu-framework-v5#keeping-boards-and-their-history-iyuuboard) in the repository README.

`Iyu.UBoard.MainServer` shares the version of the other `Iyu.*` packages of [iyu-framework-v5](https://github.com/iyulab/iyu-framework-v5) and builds on `Iyu.UBoard`, which has its own line; the [changelog](https://github.com/iyulab/iyu-framework-v5/blob/main/CHANGELOG.md) is shipped in this package, and its "Packages affected" line says which release touched which package.
